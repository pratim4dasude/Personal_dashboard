# Personal Dashboard

Portfolio site for Pratim Dasude, built with Next.js 16 (App Router), React 19 and Tailwind CSS 4.

## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

## Editing content

All text lives in `app/data.ts` (profile, experience, projects, skills). `app/page.tsx` only handles layout.
